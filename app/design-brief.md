# Design brief — Pizzeria Jogatina

- Design read: neighborhood wood-fired pizzeria in Baraki, Algiers, run by Walid. Warm, family-run, unpretentious.
- Concept spine: "the oven is the story" — the whole page is one push into the wood-fired oven, from raw dough to plated pizza.
- Delivery tier: cinema (Lenis+GSAP, Tier-1 hero = the scroll-scrub film).
- Locked palette: "Trattoria Noir" — background #14160f, surface #1b1e14, ink #f3ede0, muted ink #a9a798, single accent brick-terracotta #b3402c.
- Locked type: Cabinet Grotesk (display) + Inter Tight (body). No serif.
- Animation mode: animated-website (single-shot scroll-scrub, ~15s continuous push-in: dough -> topping -> oven -> flame -> pulled out -> sliced).
- World grammar: dim wood-fired kitchen, warm firelight key light from below, deep olive-charcoal grade, brick/amber accents, no on-screen text.
- Mobile framing: subject center-safe for 9:16 crop.
- Section plan: journey hero -> About (split text+image) -> Menu/pricing (pricing table) -> Gallery (asymmetric grid) -> Reviews (quote band) -> Hours+Location+Contact footer.
- Asset plan: generated hero film + posters, generated logo/favicon, generated interior + food photography, generated OG cover.
- CTA inventory: "Appeler" (tel: link, filled brick pill) / "Itinéraire" (maps link, outlined pill) / nav scroll links (underline-grow).

Facts sourced only from the Google Maps listing; no invented prices, awards, or history.
